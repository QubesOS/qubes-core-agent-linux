===========
qvm-copy(1)
===========

NAME
====
qvm-copy - copy specified files to a destination VM. Prompt user to select a destination VM. Does not work in dom0.

SYNOPSIS
========
| qvm-copy [--without-progress] file [file]+

OPTIONS
=======
--without-progress
    Don't display progress info
